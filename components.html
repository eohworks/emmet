Mirrors the Figma Button component's Size × State variants exactly. Product Card Complete

Mirrors the Figma Product Card component's Default/Hover variants — hover is real native CSS (.product-card:hover in styles.css), not a JS-toggled attribute, since it's a transient pointer state rather than logical state. Composes <emmet-button> internally, same as the Figma card composes a real Button instance. Hover over either card below.

Cart Drawer Draft

Proposed fuller layout — the shipped cart.js drawer (used on the live pages today) only lists items with no way to change your mind once something's added. This version keeps the exact same look/tokens but adds a quantity stepper per line item, a running subtotal, and a checkout CTA. There's no separate remove control — pressing "−" at quantity 1 removes the item, so the stepper alone covers both. Adding the same item twice bumps its quantity instead of duplicating the row. Pre-loaded with two items below so you can see the full layout immediately — try the +/− and adding more from the Button/Product Card demos above.

<emmet-cart-drawer></emmet-cart-drawer> methods: .open() .close() .addItem({name, finish, price, image})
